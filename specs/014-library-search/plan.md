# Implementation Plan: Library Search & Filter

**Branch**: `014-library-search` | **Date**: 2026-06-01 | **Spec**: [spec.md](spec.md)

## Summary

Add a live search bar to `ConfigLibraryView` (the Servers tab) that filters the server list as the user types. Match against display name and command string. Show an empty-state message when no results match. Reset on tab switch. Implementation is a small, self-contained change to one view file using the `.searchable()` modifier already used in `CatalogView`.

## Implementation Design

### Change to `ConfigLibraryView`

**1. Add state**
```
@State private var searchText: String = ""
```

**2. Add computed filter property**
```
private var filteredConfigs: [MCPServerConfig] {
    guard !searchText.isEmpty else { return store.configs }
    let q = searchText.lowercased()
    return store.configs.filter {
        $0.displayName.localizedCaseInsensitiveContains(q) ||
        $0.displayCommand.localizedCaseInsensitiveContains(q) ||
        ($0.isHTTP && $0.url.localizedCaseInsensitiveContains(q))
    }
}
```

**3. Replace `store.configs` with `filteredConfigs` in `configList`**
- `ForEach(store.configs)` → `ForEach(filteredConfigs)`
- The `body` switch between `emptyState` and `configList` stays — but when `filteredConfigs` is empty AND `searchText` is non-empty, show a search-specific empty state instead of the "No MCP Servers" message.

**4. Add `.searchable()` modifier**
```
.searchable(text: $searchText, prompt: "Search servers…")
```
Applied at the same level as `.navigationTitle`.

**5. Reset on disappear**
```
.onDisappear { searchText = "" }
```

**6. Search-specific empty state**
When `store.configs` is non-empty but `filteredConfigs` is empty:
```
ContentUnavailableView.search(text: searchText)
```
(macOS 14+) or a simple VStack with "No servers match "\(searchText)"" for broader compatibility.

### Affected views
- `ConfigLibraryView` — the only change
- `ConfigRow` — no change
- `MenuBarView` / `MainWindowView` — no change (they pass `store` via environmentObject; search state is local)
