# Contract: appcast.xml Schema

**Hosted at**: `https://rayjohnson.github.io/mcp-inator/appcast.xml`  
**Consumed by**: Sparkle framework (in-app updater)

## Schema

```xml
<?xml version="1.0" encoding="utf-8"?>
<rss version="2.0" xmlns:sparkle="http://www.andymatuschak.org/xml-namespaces/sparkle">
  <channel>
    <title>mcp-inator</title>
    <link>https://github.com/rayjohnson/mcp-inator</link>
    <description>mcp-inator releases</description>
    <item>
      <title>Version {shortVersionString}</title>
      <pubDate>{RFC-2822 datetime}</pubDate>
      <sparkle:version>{CFBundleVersion}</sparkle:version>
      <sparkle:shortVersionString>{CFBundleShortVersionString}</sparkle:shortVersionString>
      <sparkle:releaseNotesLink>{GitHub Release URL}</sparkle:releaseNotesLink>
      <enclosure
        url="{GitHub Release asset download URL}"
        sparkle:edSignature="{base64 Ed25519 signature of DMG}"
        length="{DMG file size in bytes}"
        type="application/octet-stream" />
    </item>
    <!-- older items follow, newest first -->
  </channel>
</rss>
```

## Field Rules

| Field | Required | Notes |
|-------|----------|-------|
| `sparkle:version` | Yes | Integer, must be strictly increasing. Maps to `CFBundleVersion`. Uses `GITHUB_RUN_NUMBER`. |
| `sparkle:shortVersionString` | Yes | Semver string (e.g., `0.2.0`). Maps to `CFBundleShortVersionString`. Derived from git tag. |
| `sparkle:edSignature` | Yes | Base64-encoded Ed25519 signature of the DMG file. Generated by `sign_update`. |
| `length` | Yes | Exact byte size of the DMG file. |
| `url` | Yes | Direct download URL for the DMG. Must be publicly accessible without authentication. |
| `pubDate` | Recommended | RFC 2822 format. Used for display ordering. |
| `sparkle:releaseNotesLink` | Recommended | Points to the GitHub Release page for the version. |

## Invariants

- The appcast MUST be served over HTTPS.
- Entries MUST be ordered newest-first.
- `sparkle:version` values MUST be strictly increasing across all entries.
- The `url` MUST be permanently accessible (GitHub Release assets are permanent).
- The appcast MUST remain valid XML after each release update.
